**Track B — Heap-in-Aggregate** = so that a `struct` containing a heap field (`String`/`Vector`/`HashMap`) can construct + move + drop WITHOUT leak/double-free. VISION campaign (object-model/ownership/lifetime). ADR `docs/decisions/0066-heap-in-aggregate-move-drop-glue.md` 🔒 signed by Mentor G (`ef3e54c` + amendment `a388724`). Pays down debt from ADR-0065 §4 (B8) + ADR-0062 §6.

## Recon Phase 1 (measured by Mentor O, carved in stone)
**Value-model i64 STANDS — DO NOT tear down the foundation.** A pointer can live at a field-offset inside a StackSlot (mir_lower.rs:660-665); a heap field = i64 (ptr/handle) at an offset, the same way Outcome already does it. The old limit = the construction-gate `!is_copy(None)` (refuse-over-guess), NOT physical incapacity. Lifting the gate exposes **3 holes:** (1) whole-struct copy = pointer duplicated → double-free; (2) NO struct drop-glue (`Drop(struct)`→`Unsupported`); (3) NO partial-move.

## Heap field width table (verified by Mentor O against the shim — CARVED IN STONE, get it wrong = SIGSEGV)
| Type | Width | Slot repr | Free shim | Drop-glue |
|---|---|---|---|---|
| String | **24B** fat | `{ptr@0,len@8,cap@16}` | `__triet_string_free(ptr,cap)` **2-arg** | ptr@off, **cap@off+16** |
| Vector | **8B** thin | `{ptr@0}` (len/cap in the heap) | `__triet_vector_free(ptr)` 1-arg | ptr@off |
| HashMap | **8B** thin | `{ptr@0}` | `__triet_hashmap_free(ptr)` 1-arg | ptr@off |

## 3 KCN + IRON LAW (signed by Mentor G)
- **KCN-1 Inline per-struct static drop-glue** (header/v-table FORBIDDEN): JIT walks the layout, statically emits `free(ptr@offset)` for each heap field. Zero runtime overhead.
- **KCN-2 Copy-then-tombstone**: Assign-move (`let q=p`) byte-copy + tombstone-source ATOMIC. Arg-move (`take(p)`) = by-pointer + `Deinit`-after-call (reuses ADR-0042, NOT a byte-copy at the call site — diagram amended in Recon-2).
- **KCN-3 FLAT only**: recursive `Node{next:Node?}` deferred to Slice 2.
- **⚖️ ATOMIC IRON LAW** (carved at the head of the ADR): `byte-copy → tombstone` in the same basic-block, panic/CFG-branch/call interleaving FORBIDDEN. Slipping through the gap = double-free. Violation = REJECT without reading.
